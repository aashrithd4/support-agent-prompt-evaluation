# IT-support prompt lifecycle demo

This package includes the deployed agent source, a local evaluation harness, the 40 synthetic development tasks, the three prompts and the recorded runs. The reported results come from `run_eval.py`, **not** AgentCore managed Evaluations. V3 was generated by `optimize_v3.py`, **not** AgentCore Recommendations.

## Files
- `agent.py`: AgentCore Runtime agent that reads bundle configuration when constructing an agent per request. No live bundle-switch or rollback validation is included.
- `run_eval.py`: local Strands evaluation using Bedrock model and judge calls.
- `optimize_v3.py`: separate Bedrock prompt optimization call.
- `prompts.json`: the three prompt versions.
- `results/dataset.json`: the 40 development tasks.
- `results/runs/`: recorded per-task responses and judgments.

## Reproduce
Install `requirements.txt`, configure AWS credentials with model access in `us-west-2`, then run `python run_eval.py v1 v1`, `python run_eval.py v2 v2`, and `python run_eval.py v3 v3`. These calls incur AWS charges. Running again may produce different responses or scores. Do not interpret 40/40 as out-of-sample performance because V2/V3 used this dataset during development.

This is a sanitized source package, not a complete infrastructure-as-code deployment. Fictional `.corp` addresses are sample knowledge-base text.
